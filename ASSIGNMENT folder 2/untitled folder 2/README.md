# Customer Churn Prediction using Logistic Regression

## Objective

Predict whether a telecom customer will churn using Logistic Regression.

## Dataset

https://www.kaggle.com/datasets/blastchar/telco-customer-churn

## Libraries Used

- pandas
- numpy
- scikit-learn

## Methodology

- Data Loading
- Data Cleaning
- Encoding Categorical Variables
- Train-Test Split
- Logistic Regression
- Model Evaluation

## Results

Accuracy : 78.61%

Precision : 62.29%

Recall : 49.47%

F1 Score : 55.14%

## Conclusion

The model achieved nearly 79% accuracy and identified important factors affecting customer churn. Logistic Regression works well but may struggle with complex non-linear relationships.
